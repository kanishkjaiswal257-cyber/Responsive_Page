# Northstar — Modern Responsive Landing Page

A sleek, responsive, and thoughtfully crafted landing page for **Northstar**, an independent creative studio. Built with **React 19** and **Vite**, featuring modern styling, smooth section navigation, and responsive typography.

---

## ✨ Features

- **Responsive Design**: Fluid layout adapting seamlessly across mobile, tablet, and desktop screens.
- **Scroll-Aware Navigation**: Sticky header that updates its background and highlights the active section in real time as the user scrolls.
- **Mobile Navigation**: Accessible slide-out hamburger navigation menu with smooth transitions.
- **Visual Polish**:
  - Ambient hero glow with modern typography and subtle entrance cues.
  - Interactive project cards highlighting selected creative work with hover depth.
  - Numbered service breakdowns with structured hierarchy.
  - Clean contact and call-to-action sections.
- **Lightning-Fast Performance**: Powered by Vite 6 with instant Hot Module Replacement (HMR).

---

## 🛠️ Tech Stack

- **Framework**: [React 19](https://react.dev/)
- **Build Tool**: [Vite](https://vitejs.dev/)
- **Styling**: Vanilla CSS with modern CSS custom properties, CSS Grid, and Flexbox
- **Linter**: [Oxlint](https://oxc.rs/)

## 🚀 Getting Started

### Prerequisites

Ensure you have [Node.js](https://nodejs.org/) installed (v18 or higher recommended).

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/kanishkjaiswal257-cyber/Responsive_Page.git
   ```

2. Navigate to the project directory:
   ```bash
   cd Responsive_Page
   ```

3. Install dependencies:
   ```bash
   npm install
   ```

4. Start the development server:
   ```bash
   npm run dev
   ```

5. Open your browser and navigate to `http://localhost:5173`.

---

## 📦 Scripts

- `npm run dev` - Launch the Vite development server.
- `npm run build` - Build production-ready bundle into the `dist/` directory.
- `npm run preview` - Preview the production build locally.
- `npm run lint` - Run Oxlint code checks.
